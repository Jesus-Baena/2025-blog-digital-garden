Llevo usando Obsidian más de tres años. Lo utilizo como sistema de Gestión de Información Personal (PIM), como repositorio de Proyectos y como sistema de [[Personal Knowledge Management]] (PMS).

Este blog es un subconjunto de mi configuración completa de Obsidian. Esta es una captura de pantalla de su aspecto.

![[Pasted image 20250812084447.png]]

He probado muchos otros sistemas: *Notion, Heptabase, Logsec, Anytype*... Todas son soluciones estupendas, pero siempre acabo volviendo a Obsidian.

Para la **sincronización** de mis notas entre dispositivos, utilizo el servicio oficial que ofrece Obsidian. Paradójicamente, el lugar donde desarrollo mis proyectos autohospedados no está autohospedado. Aunque esto va a cambiar pronto.

Para la **publicación** de este blog, utilizo un proyecto de código abierto, [Quartz](https://quartz.jzhao.xyz/). Solo he hecho cambios menores que se pueden copiar desde [mi repositorio público](https://github.com/Jesus-Baena/009-baena.blog-personal-pkm) en GitHub. He cambiado el pie de página y el filtrado del explorador.

Para el **alojamiento**, utilizo Cloudflare Pages. La facilidad de despliegue mediante Workers es insuperable. Hago commit en mi repositorio de GitHub y automáticamente lo recoge el Worker de Cloudflare para construirlo y servirlo.
